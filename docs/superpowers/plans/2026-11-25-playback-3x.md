# 菜单 3 倍速与右方向键长按

**Goal:** 点播速度菜单增加 3 倍；按住右方向键暂时 3 倍，轻点仍快进一次。

**Architecture:** 纯函数生成速率列表。另一个纯状态机处理右方向键的按下、重复、松开和取消。播放器只负责把 ArtPlayer 静态列表换掉，并把现有快捷键接到这个状态机。

**Tech Stack:** ArtPlayer 5、Vitest 假定时器。版本保持 2.21.2。

## Global Constraints

- 基线 `af445c1`，不改代理和自动停用修复，不改 `main`
- 不新增持久化设置，不把默认倍速改成 3
- 直播播放器保持 `playbackRate: false`
- 触摸长按仍是暂时 3 倍并在松手后恢复
- 不请求真实影片
