# 菜单 3 倍速与右方向键长按

基线：`af445c1`（LibreTV 2.21.2）。保留「不自动停用点播源」和「HTTP 代理钉死 IP」。不改 `main`，不合并。

已批准：速度菜单加上 3 倍，其余档位和顺序不变。另加一个范围明确的键盘手势：按住右方向键暂时 3 倍，松开回到按下前的倍速；轻点仍只快进一次。

## 菜单

ArtPlayer 的 `PLAYBACK_RATE` 现在是 `[0.5, 0.75, 1, 1.25, 1.5, 2]`。点播播放器在 `new Artplayer` 之前把它换成原列表末尾加一个 `3`（已有 `3` 则不重复）。设置面板和桌面右键菜单都读这个静态数组，全屏和移动端设置共用这一份。直播播放器 `playbackRate: false`，不改。

选中 3 倍走现有的 `video:ratechange`：把 `defaultPlaybackRate` 写成当前倍速，换集时浏览器的归位不会把它打回 1。不新增设置项，不写入 localStorage，不做滑杆，不把默认倍速改成 3。

## 键盘

`hotkey: false`，右方向键只由 `player-shell` 的监听处理，每次 `keydown`（含按住后的重复）都会 `currentTime += 5`。长按因此会连跳。

只处理没有 Alt/Ctrl/Meta/Shift 的 `ArrowRight`。带这些修饰键时保持原样（Alt 仍交给上一集/下一集，其余修饰键仍按原来的立即快进）。输入框、文本域、`contenteditable` 和按钮上不拦截。

阈值 500 毫秒，与播放器里已有的触摸长按 3 倍相同。ArtPlayer 自带的快进插件没有打开。

- 按下：开始计时，不快进。
- 500 毫秒内松开：只快进一次，条件和原来一样（离结尾多于 5 秒才 `+5`）。
- 到点：只把倍速设为 3 一次，并记住按下前的倍速。重复的 `keydown` 不重新计时，也不覆盖记住的倍速。
- 松开：回到记住的倍速，即使原来就是 3。长按期间不快进。
- 暂停时不进入 3 倍，松开仍只快进一次。
- 失焦、页面隐藏、换集、播放器销毁：清掉计时器；如果已经临时加速，先恢复记住的倍速，不快进。

触摸长按 3 倍的按下/松开逻辑保持不变，只把 500 毫秒改成同一个常量。
